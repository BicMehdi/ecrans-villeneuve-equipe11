# Diagrammes du DAT

Les sources `.drawio` sont modifiables dans diagrams.net. Les exports PNG portant les mêmes noms sont insérés dans le DAT.

- `0-event-storming` — vente et abonnements
- `1-contexte` — acteurs, billetterie et systèmes externes
- `2-context-map` — frontières, sens amont et aval, patterns de collaboration
- `3-composants-vente` — ports, adapters et agrégats du contexte Vente
- `4-sequence-reserver-payer` — confirmation et expiration d’une réservation
- `5-modele-vente` — agrégats, objets valeur et événements
